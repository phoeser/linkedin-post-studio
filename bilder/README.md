# Bilder

Öffentlich erreichbare Bilder für Instagram.

Instagram lädt das Bild beim Veröffentlichen **selbst** von einer URL herunter.
Google-Drive-Links funktionieren dafür nicht — die Instagram-API kann Dateien
von Drive nicht lesen. Deshalb liegt hier eine Kopie jedes Bildes, das auf
Instagram gehen soll.

Öffentliche Adresse:

    https://phoeser.github.io/linkedin-post-studio/bilder/<dateiname>

Die Dateien legt Make automatisch ab (Route `action=ghimg` im Szenario
"LinkedIn Tool → Sheet", 9665511). Der Dateiname enthält eine Zufallsfolge,
damit niemand ein noch nicht veröffentlichtes Bild erraten kann.

**Alles in diesem Ordner ist öffentlich** und bleibt in der Git-Historie
stehen, auch nach dem Löschen. Nur Bilder ablegen, die ohnehin veröffentlicht
werden.
